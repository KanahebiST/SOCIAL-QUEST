# SOCIAL QUEST（ソーシャルクエスト）

**あなたの行動が、未来を育てる。**

現実世界での社会貢献活動をゲーム感覚で楽しめるWebアプリです。
社会貢献するとポイント（SOCIAL XP）が貯まり、そのポイントに応じてアバターの装飾品や背景が解放されていきます。

「社会貢献する → XPが貯まる → アバターが成長する → 新しいアイテムが解放される → 自分だけのアバターを作る」
というゲーム性を通じて、社会問題を知るきっかけと、実際の社会貢献活動への参加を促すことを目的としています。

対象ユーザーは主に10代〜20代。ゲームアプリのように直感的に操作できる、明るく親しみやすいUI/UXを目指しています。

## 主な機能

### 🏠 ホーム画面
- アバター、現在のレベル、SOCIAL XP、次のレベルまでの必要XPを表示
- 今日のおすすめミッション、最近獲得したアイテム、カテゴリ別の貢献度を確認可能

### 🌱 社会貢献の記録
以下5カテゴリの活動を登録してXPを獲得できます（デモ仕様・外部連携なし）。

| カテゴリ | アイコン | 例 |
|---|---|---|
| 環境 | ♻️ | ペットボトル/缶のリサイクル、エコバッグ・マイボトル使用 |
| 支援 | 💰 | 募金、寄付、支援キャンペーン参加 |
| 地域 | 🏘️ | 地域清掃、地域イベント参加 |
| ボランティア | 🤝 | ボランティア活動、福祉活動 |
| 学習・啓発 | 📚 | 社会問題の記事を読む、啓発イベント参加 |

> お金を多く使った人だけが有利にならないよう、リサイクル・ボランティア・学習・地域活動など、誰でも参加しやすい活動からも十分にXPを獲得できる設計です。

### ⭐ レベル&アイテム解放システム
- XPが貯まるとレベルアップ演出とともに新アイテムが解放
- レベルだけでなく「どの社会貢献をしたか」によって解放アイテムが変化（例：環境活動→植物アクセサリーや葉っぱのエフェクト、支援活動→光のアクセサリー、地域活動→街をイメージした背景 など）

### 🌳 SOCIAL TREE
社会貢献度に応じて成長する木をホーム画面に表示。種→芽→小さな木→大きな木→開花→光る木、と成長し、活動カテゴリによって変化の仕方も変わります。

### 🎯 ミッション&実績
- 今日のミッション／今週のミッションで追加報酬を獲得
- 実績（Achievement）をクリアするとバッジを獲得

### 📊 貢献履歴・貢献プロフィール
- これまでの活動履歴と合計XPを一覧表示
- カテゴリ別の貢献割合をグラフで可視化し、「エコロジスト」「コミュニティメーカー」などの貢献タイプを判定

### 🌍 世界樹（ワールドツリー）
全ユーザーの社会貢献を合計して成長する、コミュニティ全体のシンボル（MVPではモックデータ）。

## アバターカスタマイズ

2Dレイヤー方式（背景→体→服→髪→アクセサリー→特殊エフェクト）でアバターを構成。

- **体**：肌の色、髪型、髪色
- **服**：シャツ、ジャケット、パーカー、制服風衣装、スポーツウェア
- **アクセサリー**：帽子、メガネ、イヤリング、ネックレス、バッグ
- **特別**：光るエフェクト、オーラ、羽、ペット、特別な背景

## 画面構成（ナビゲーション）

🏠 ホーム / 🌱 クエスト / 🌍 ソーシャル / 🧑 アバター / 👤 プロフィール

## データ保存

MVPではブラウザの `localStorage` にユーザーデータ（XP・レベル・アバター・解放アイテム・活動履歴・実績）を保存し、リロードしても消えない構成です。将来的にはFirebaseなどのバックエンドへの移行を想定しています。

## 使用技術

- TypeScript
- Google AI Studio（Gemini）を用いて構築

## 開発の思想

「お金をたくさん使った人が一番偉い」という価値観にはしません。ペットボトルのリサイクル、地域の清掃、社会問題について学ぶこと、誰かを助けること、募金など、あらゆる行動に等しく価値を見出すことを大切にしています。
